# Security policy

Do not open a public issue with a vulnerability or customer data. Report a suspected vulnerability privately through GitHub's security advisory workflow for this repository, or contact the maintainers privately through the repository owner. Include reproduction steps, affected version, impact, and any safe proof of concept. Do not send production credentials or telemetry.

Supported versions and a response SLA will be published before production release. Until then this repository is a pre-release UI scaffold. Engineering rules for auth, tenant boundaries, and sensitive data are in [docs/SECURITY.md](docs/SECURITY.md).
